sec-email-address
====================

邮件网关按邮箱身份判定是否放行，最近出现同一邮箱换个写法就绕过封禁、合法用户换个显示名却被判成两个人：契约要求一封地址拆成显示名、本地部分与域名三部分，显示名去两端空白、成对双引号去掉但引号内转义按字面还原；本地部分保留原始大小写，属于点原子时每段必须非空（首尾点与连续点都非法）且不含空白与特殊字符，带引号时去掉外层引号并还原反斜杠转义，引号内的 @ 不参与切分、切分点取最后一个引号外的 @；域名大小写不敏感，统一转小写并把国际化标签转成 punycode（非 ASCII 标签写成 xn-- 形式），输入是 punycode 时保持不变；规范化结果只由本地部分与规范化后的域名拼接而成，显示名一律丢弃，同一邮箱的不同书写（大小写、显示名、Unicode 与 punycode、括号注释）必须落到同一个字符串；地址列表按逗号切分，但引号内、尖括号内与括号注释内的逗号不算分隔符，组语法的"组名冒号 成员逗号分隔 分号"要展开成成员本身、组名与分号不出现在结果里，空片段直接忽略；判断两个书写是否同一邮箱只看规范化结果，与显示名无关。不变量：规范化幂等；显示名变化不改变规范化结果；Unicode 与 punycode、大小写不同的域名书写互相等价；列表展开后的每一项与单独解析同一片段的结果一致。
